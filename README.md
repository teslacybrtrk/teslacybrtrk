<summary>How does this work?</summary>

Each **🏐 Throw** link opens a pre-filled issue. When you submit it, a [GitHub Action](.github/workflows/smash.yml) runs [`game/smash.py`](game/smash.py), updates [`game/state.json`](game/state.json), redraws the truck, commits the new README and closes your issue with a reply. There's no server. The whole game lives in this repo.
